For the technical task, I decided to create a sensor that senses random distance readings. I first created two nodes, a publisher node called distance_publisher, and a subscriber node called distance_subscriber. By using python’s built in random library, I can generate random distance readings (in my case, 0.2 to 5 meters), and publish the readings to the topic “distance_of_robot”. After that, I use the subscriber node, which listens to the topic given and prints the received distance values.

Such data is useful in robotics when it comes to navigation and danger sensing. A robot can not only use distance readings to detect any nearby obstacles, but to avoid collisions from obstacles, as well as make movement decisions from it. For example, when a robot detects that it is too close to an object, it can stop, slow down, or move away from the object. Another example is a robot using sensor readings to follow a path or navigate an environment. This is also useful for autonomous navigation.
